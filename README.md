# **Лабораторная работа №08 - Метод анализа иерархий**

## Задание
Написать программу, реализующую метод анализа иерархий Томаса Саати для одного уровня.

Входные данные: количество критериев, данные попарного сравнения критериев (запрашиваются попарно).

Выходные данные: весовые коэффициенты критериев в виде 0.00.

Требования к качеству: комментарии к функциям и основным блокам (поясняют, зачем сделано), понятный диалог с пользователем, обработка ошибок ввода.

## Описание программы
Программа запрашивает количество критериев, их названия и попарные сравнения по шкале Саати. По ответам строится матрица попарных сравнений, затем вычисляются весовые коэффициенты критериев: сумма элементов строки делится на сумму всех элементов матрицы. Сумма весов равна 1.

Шкала сравнения: 1 - равная важность, 3 - умеренное превосходство, 5 - существенное, 7 - значительное, 9 - очень сильное, 2, 4, 6, 8 - промежуточные значения. Если второй критерий важнее первого, вводится обратная дробь (1/3, 1/5 и т.д.).

## Среда разработки

Язык программирования: Python 3.

Проект можно открыть в PyCharm.

Файл проекта, который нужно открывать: `ahp.py`.

## Инструкция по работе

### Запуск
Открыть файл `ahp.py` в PyCharm и запустить его (Shift+F10) или выполнить в терминале:
```
python ahp.py
```

### Как пользоваться
Программа по очереди запрашивает:
1. Количество критериев (от 2 до 10).
2. Название каждого критерия. Если нажать Enter, будет использовано название «Критерий N». Названия не должны повторяться.
3. Сравнение каждой пары критериев: число от 1 до 9 или дробь от 1/2 до 1/9. Каждая пара запрашивается один раз, обратные значения программа вычисляет сама.

В конце программа выводит матрицу попарных сравнений и весовые коэффициенты в виде 0.00.

При неверном вводе (не число, число вне диапазона, деление на ноль, повторяющееся название) программа выводит сообщение об ошибке и повторяет вопрос.

## Тесты

### Тест 1 - 3 критерия, ввод с ошибками
Критерии: Цена, Качество, Сроки.

Ошибочный ввод: `abc`, `1` и `11` для количества критериев; повторное название `Цена`; значения `0`, `10`, `abc` для первого сравнения; `1/0` для второго. Программа сообщает об ошибках и повторно задаёт вопрос. Далее введены значения 1/3, 3, 5.

Результат: Цена 0.29, Качество 0.61, Сроки 0.10.
